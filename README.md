# Freight Cost Calculator

This project is a **desktop freight cost calculator** developed in Python using the Tkinter library. It simulates a real-world logistics scenario by calculating shipping costs based on cargo weight and transport distance.

---

## Project Overview

The application allows users to enter the weight of a shipment and the distance to be traveled. Based on predefined business rules, the system calculates and displays the estimated freight cost in a clear and user-friendly interface.

The project focuses on practicing **desktop application development**, **input validation**, and **business rule implementation** using Python.

---

## Features

- Graphical user interface built with Tkinter  
- Freight cost calculation based on weight and distance  
- Input validation to prevent invalid or negative values  
- Error handling with user-friendly messages  
- Simple and intuitive desktop layout  

---

## Technologies Used

- Python 3  
- Tkinter  

---

## Business Rules

The freight cost is calculated using the following logic:

- Base cost  
- Cost per kilometer traveled  
- Cost per kilogram transported  

This approach simulates a simplified pricing model commonly used in logistics systems.
